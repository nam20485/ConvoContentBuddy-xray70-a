## Project References

### Aspire AppHost Dependencies
- ConvoContentBuddy.API.Brain
- ConvoContentBuddy.UI.Web
- ConvoContentBuddy.Data.Seeder

### Service References
- Redis (SignalR backplane, caching)
- PostgreSQL (graph database with pgvector)
- Qdrant (vector database)

### Key Technologies
- **Framework**: .NET 10.0, ASP.NET Core 10
- **AI**: Microsoft.SemanticKernel, Gemini 2.5 Flash
- **Frontend**: Blazor WebAssembly 10
- **Databases**: Qdrant (vectors), PostgreSQL + pgvector (graph)
- **Real-time**: SignalR with Redis backplane
- **Resilience**: Polly (circuit breaker, retry policies)

## Architecture Overview

### Layer 1: Audio Input & Transcription
- Browser-based Web Speech API (webkitSpeechRecognition)
- JavaScript Interop layer (speechInterop.js)
- Blazor WASM client

### Layer 2: Context & Intent Analysis ("The Brain")
- ASP.NET Core 10 API with Semantic Kernel
- Gemini 2.5 Flash for problem identification
- Hybrid Retrieval Service

### Layer 3: Resource Retrieval (Hybrid Chain)
- VectorSearchProvider (Qdrant gRPC)
- GraphTraversalProvider (PostgreSQL)
- LLM Verification via Gemini

### Layer 4: Ambient UI
- Blazor WebAssembly
- SignalR client with Redis backplane
- Real-time solution cards

### Prerequisites
